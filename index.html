Тренажёр — интерактивный чат с виртуальным жильцом для отработки возражений. У агентов на странице «Тренажёр» есть выбор: печатать или говорить голосом (клиент тоже отвечает голосом) — это работает в браузере бесплатно, без дополнительных настроек. Подключите сюда API-ключ Anthropic (Claude), и клиент в тренажёре начнёт по-настоящему понимать смысл ответов агентов, а не просто искать ключевые слова. Без ключа тренажёр всё равно работает — в упрощённом демо-режиме.

Ключ будет доступен всем агентам через страницу «Тренажёр» — вводить его им не нужно. Учтите: технически ключ виден в браузере агента (это ограничение работы ИИ прямо в браузере без своего сервера), поэтому используйте ключ с лимитом расходов, настроенным в консоли Anthropic.
